# Premium Business Website (Aura Enterprise)

A high-performance, custom-built business web application modeled on the layout flow, visual hierarchy, and structural polish of **PayPal Australia**.

Built with:
- **Next.js 14+ (App Router)**
- **Tailwind CSS** (Fluid typography & mathematical spacing)
- **Framer Motion** (Hardware-accelerated scroll reveals and interactive carousels)
- **Lucide React** (Crisp enterprise iconography)

---

## 10 Integrated Homepage Sections

1. **Header & Navigation**: Sticky frosted-glass navbar with responsive animated mobile menu.
2. **Hero Section**: High-impact split layout with live status matrix and responsive action buttons.
3. **Value Proposition**: Editorial typography statement with 3 value pillars.
4. **Services & Solutions Grid**: 3-column interactive service cards with hover glows and sub-CTAs.
5. **Brand Statement**: Full-bleed typographic impact banner.
6. **Featured Solutions**: Alternating image/text deep-dive rows.
7. **About / Credibility**: 4-column metric counter matrix with enterprise SLA markers.
8. **Testimonials & Case Studies**: Interactive client endorsement deck with star ratings and slider controls.
9. **Final Conversion CTA**: High-contrast, full-width conversion closer.
10. **Footer**: 4-column link matrix, system health indicator, and legal/compliance disclosures.

## Quickstart & Local Development

1. Navigate to the project directory:
   ```bash
   cd C:\Users\vence\.gemini\antigravity\scratch\premium-business-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Content Customization

All copy, metrics, and navigation links are decoupled in [`content/siteData.ts`](file:///C:/Users/vence/.gemini/antigravity/scratch/premium-business-website/content/siteData.ts). You can update text, add new services, or swap client testimonials without altering component code.
